Title: feat(core): read PDFs and images, with OCR for scanned documents
Labels: priority: P0

## Why
The extractor and the citation check both need the document's text per page. Scanned receipts (all of SROIE) have no text layer, so OCR is required from day one.

## Scope
- `ingest(path) -> Document` with `pages: list[PageText]` (page number, text, `source: text_layer | ocr`).
- PDF with a text layer: read it directly. PDF without text, or image (JPG/PNG): OCR.
- Choose the libraries after checking official docs and licenses (for example, pypdf or pdfplumber for text; Tesseract via pytesseract, or another OCR) and record the choice in `docs/ARCHITECTURE.md`. Note the system dependency OCR adds to CI.
- Clear errors for unsupported type, unreadable file and empty result.

## Acceptance criteria
- [ ] Tests, seen failing first, with small fixtures generated in the test (no client data): text PDF read without OCR; image read with OCR and the expected words found; unsupported extension raises a named error.
- [ ] CI installs the OCR dependency and runs these tests.

## Out of scope
Layout analysis, tables, bounding boxes.

Estimate: ~3 h
