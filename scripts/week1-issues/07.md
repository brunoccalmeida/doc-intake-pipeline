Title: feat(core): structured run log and cost per document
Labels: priority: P1

## Why
Clients ask "how much will this cost per document?" and "what happened with this one?". See `docs/ARCHITECTURE.md` D5.

## Scope
- Structured log (JSON lines) per document: run id, document id, pack, provider, model, latency, input/output tokens, retries, status, validation errors. No document text by default.
- Price table versioned in the repo with date and link to the official pricing page; cost computed in `Decimal` USD from token usage.
- Eval report and CLI summary show total and average cost per document.

## Acceptance criteria
- [ ] Tests, seen failing first: cost computed from usage and price table; unknown model fails loudly instead of logging cost 0; log line contains no document text (asserted).
- [ ] Average cost per document visible in the eval report.

## Out of scope
Dashboards, external log shipping.

Estimate: ~1.5 h
