Title: test(evals): golden set of 20 SROIE receipts converted to the schema
Labels: priority: P0

## Why
Without a golden set there is no eval, and without an eval every accuracy claim is a guess. See `docs/ARCHITECTURE.md` D6.

## Scope
- **First, the license:** find the dataset's license at the source (the ICDAR 2019 SROIE competition / the organizers), not only on a mirror, and record it with links in `docs/DATA.md`, including the required attribution. If redistribution is not clearly allowed, do not commit the images: commit a download script pinned to an exact revision with checksums, plus the converted ground truth if allowed.
- Pick 20 receipts with a documented, reproducible rule (for example, a fixed seed over the test split), including some low-quality scans.
- Convert SROIE's ground truth (`company`, `address`, `date`, `total`) to the `Receipt` schema; normalize dates and totals with the same functions the pack uses.
- Fix ground truth only with evidence (the image shows otherwise), each fix listed in `docs/DATA.md`.

## Acceptance criteria
- [ ] `docs/DATA.md` with source, license, attribution, selection rule and corrections.
- [ ] All 20 ground-truth files validate against the schema (test).
- [ ] Fetching the set from a clean clone is one command and is verified by checksum.

## Out of scope
CORD and CUAD.
